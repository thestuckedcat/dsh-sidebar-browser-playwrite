# DSH 侧栏浏览器产品形态

在 DSH Desktop 会话中，用户让 Agent 打开网站、查看页面、点击或填写表单。当前会话右侧的 **Agent 浏览器** 标签展示同一页面，用户可以直接滚动、输入或接手。右栏由 DSH 管理，网页由 DSH 隔离的 Electron guest 渲染。

| ID | 首版行为 | 状态 | 验收 |
| --- | --- | --- | --- |
| SB-P01 | Agent 打开并直接控制用户看到的右侧页面，网页由桌面应用承载 | 用户已确认「Agent打开侧栏网页，并直接桥接控制网页。不要运行独立chromium」 | 一次导航、一次点击、一次填写都用同一个侧栏 guest |
| SB-P02 | 当前本机的 DSH Desktop 0.2.1-rc.5 为首版验证基线，工具入口沿用 `browser_*` | 设计决定，沿用已实测的版本和上游工具 | 隔离 desktop profile 可装载，注册后可执行工具 |
| SB-P03 | 把代码上传到用户指定的 GitHub 仓库 | 用户已授权 | 远端分支可找到交付提交 |

侧栏标签和站点状态随 DSH Desktop 进程运行，关闭标签会释放该标签下的网页。操作要求发起会话处于当前桌面界面。切回该会话并重新观察即可恢复操作。卸载通过 DSH 插件管理器或 desktop profile 的移除命令。
